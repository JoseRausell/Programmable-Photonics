Microring weight bank

Theory

1 · Broadcast-and-weight

Each input value xk travels on its own wavelength λk. All the channels share one waveguide (wavelength-division multiplexing), so a single photodetector can add them up. The weighted sum is a dot product, the core operation of a neural-network neuron:

y = Σk wk xk

Each operation happens at the speed of light, with no data movement between memory and processor.

2 · Inputs: all-pass ring modulators

A ring next to the bus removes power near its resonance. Detuning the ring from its channel with a heater (or a carrier-depletion junction) sets the transmitted power:

Tap(φ) = a² − 2ra cos φ + r²1 − 2ar cos φ + (ra)²,   φ = 2π λres − λFSR

Here the modulators are assumed critically coupled (a = r), so Tap goes from 0 on resonance to ≈ 1 far away and covers the full range of x.

3 · Weights: add-drop rings and balanced detection

In the weight bank every add-drop ring splits its channel between the drop port and the through port:

D = (1 − r²)² a1 − 2r²a cos φ + r⁴a²,    T = r²(1 + a² − 2a cos φ)1 − 2r²a cos φ + r⁴a²

A balanced photodetector subtracts the through port from the drop port, so each channel is multiplied by

wk = D(λk) − T(λk) ∈ [≈ −1, D0 − T0]

On resonance most of the light goes to the drop port (positive weight); far from resonance it stays in the through port (weight −1). Negative weights come for free with balanced detection.

4 · Inter-channel crosstalk and calibration

The Lorentzian tails of each ring also act on the neighbouring channels. If each ring is set as if it were alone, the realized weights deviate from the targets, more so when the channel spacing is only a few linewidths:

FWHM ≈ FSR𝓕,   𝓕 = π √(r²a)1 − r²a

Practical weight banks calibrate the whole bank together: the detunings are adjusted iteratively using a model (or measurements) of all the rings, so that the realized weights match the targets. Switch on crosstalk-compensated to see it.
