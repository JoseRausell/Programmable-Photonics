Two architectures for the same job

1 · Linear optics is unitary

A lossless linear circuit with N inputs and N outputs relates the output fields to the input fields through a unitary matrix, Eout = U Ein with U†U = I. A matrix of U(N) has N² real parameters.

The building block is the MZI with an internal phase θ and an external phase φ (see the MZI page). It implements any 2×2 transformation up to output phases:

T(θ, φ) = j ejθ/2ejφ sin(θ/2)cos(θ/2)ejφ cos(θ/2)−sin(θ/2)

θ = π is the bar state, θ = 0 the cross state, and θ = π/2 a 50:50 split.

2 · Decomposition into 2×2 rotations

Any U can be factorized into N(N−1)/2 MZIs Tm,m+1, each acting on two neighbouring waveguides, followed by a diagonal screen of N output phases:

U = D · Π(m,n) Tm,m+1(θ, φ),    2 · N(N−1)2 + N = N²

The phases are found by nulling: multiply U by MZI matrices chosen to set one element to zero at a time, until only a diagonal is left. The order of the nulling defines the topology of the mesh.

3 · Reck (1994): triangular mesh

The rows are nulled from the bottom, using multiplications from one side only. The MZIs form a triangle:

  • number of MZIs: N(N−1)/2
  • optical depth: 2N − 3 MZI columns
  • light from different inputs crosses very different numbers of MZIs (from 1 up to 2N−3)

Paths of unequal length accumulate unequal loss, which distorts the transformation. The long paths also accumulate more phase errors.

4 · Clements (2016): rectangular mesh

Rows and columns are nulled alternately from both sides. The left-hand factors are then moved through the diagonal using T⁻¹D = D′T′:

  • same number of MZIs: N(N−1)/2
  • optical depth: N columns, about half of Reck's
  • every path crosses a similar number of MZIs, so loss is balanced

The result is a more compact mesh that is more tolerant to loss, and the preferred choice in today's photonic processors.

5 · Imperfections and fidelity

Real MZIs have MMI imbalance (α), phase errors and loss. The quality of the implemented matrix T is measured with the fidelity:

F = |Tr(U†T)|²N · Tr(T†T)

Random phase errors degrade both meshes similarly, because both have the same number of MZIs. Loss is different: in Reck it depends on the path, so F drops faster, while Clements keeps it almost uniform. Try both in the simulations (Monte Carlo plots).

6 · Applications

  • Optical matrix–vector multiplication for neural networks (inference at the speed of light).
  • Linear-optical quantum computing and boson sampling.
  • Reconfigurable switches and routers, mode (de)multiplexing and unscrambling.
  • Beamforming networks and optical signal processing.
