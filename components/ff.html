Two architectures for the same job

1 · Linear optics is unitary

A lossless linear circuit with N inputs and N outputs relates the output fields to the input fields through a unitary matrix, Eout = U Ein with U†U = I. A matrix of U(N) has N² real parameters.

The building block is the MZI with an internal phase θ and an external phase φ (see the MZI page). It implements any 2×2 transformation up to output phases:

T(θ, φ) = j ejθ/2ejφ sin(θ/2)cos(θ/2)ejφ cos(θ/2)−sin(θ/2)

θ = π is the bar state, θ = 0 the cross state, and θ = π/2 a 50:50 split.

2 · Decomposition into 2×2 rotations

Any U can be factorized into N(N−1)/2 MZIs Tm,m+1, each acting on two neighbouring waveguides, followed by a diagonal screen of N output phases:

U = D · Π(m,n) Tm,m+1(θ, φ),    2 · N(N−1)2 + N = N²

The phases are found by nulling: multiply U by MZI matrices chosen to set one element to zero at a time, until only a diagonal is left. Each nulling fixes one MZI (θ, φ). The order of the nulling defines the topology of the mesh.

Nulling from the right (mixes columns m, m+1). Take two neighbouring elements of one row, a = Wr,m and b = Wr,m+1. After W → W·T†m,m+1 the new left element is a e−jφ sin(θ/2) + b cos(θ/2) (times a phase), which vanishes for

θ = 2 atan |b||a|,    φ = arg(−a / b)

Nulling from the left (mixes rows m, m+1). Take two neighbouring elements of one column, a = Wm,c and b = Wm+1,c. After W → Tm,m+1·W the new lower element is ∝ a ejφ cos(θ/2) − b sin(θ/2), which vanishes for

θ = 2 atan |a||b|,    φ = arg(b / a)

The modulus ratio fixes the splitting (θ) and the relative phase fixes φ. Because the MZI is unitary, the zeros created before are never destroyed, as long as the order is chosen properly.

3 · Reck (1994): triangular mesh

The algorithm uses multiplications from the right only:

  1. Start with W = U.
  2. Last row (N): null WN,1, WN,2, …, WN,N−1 from left to right. Element WN,c is nulled with an MZI on columns c, c+1, pushing the power of the row to the right. Since the row has unit norm, WN,N ends with |·| = 1, and by unitarity the rest of column N becomes zero too.
  3. Repeat with row N−1 (elements 1 … N−2), then row N−2, … down to row 2.
  4. After N(N−1)/2 steps, U · T†1 ⋯ T†K = D is diagonal, so U = D · TK ⋯ T1: the first MZI found is the first one crossed by the light. The phases of D are the output phase shifters.
  • number of MZIs: N(N−1)/2
  • optical depth: 2N − 3 MZI columns
  • light from different inputs crosses very different numbers of MZIs (from 1 up to 2N−3)

Paths of unequal length accumulate unequal loss, which distorts the transformation. The long paths also accumulate more phase errors.

4 · Clements (2016): rectangular mesh

The lower-left triangle of U is cleared diagonal by diagonal, alternating the side:

  1. For i = 1 … N−1 take the i-th anti-diagonal of the lower triangle.
  2. i odd: null its elements from bottom to top from the right, W → W·T†. These MZIs sit at the input side of the mesh.
  3. i even: null its elements from top to bottom from the left, W → T·W. These MZIs belong to the output side.
  4. At the end TL ⋯ U ⋯ T†R = D, i.e. U = T†L ⋯ D ⋯ TR.
  5. Commute each inverse left factor through D, starting with the one next to it: T⁻¹(θ, φ) · diag(dm, dm+1) = V = diag(d′m, d′m+1) · T(θ′, φ′), with θ′ = 2 acos|V12|. Every MZI ends with the standard (θ′, φ′) form and D moves to the output.
  • same number of MZIs: N(N−1)/2
  • optical depth: N columns, about half of Reck's
  • every path crosses a similar number of MZIs, so loss is balanced

The result is a more compact mesh that is more tolerant to loss, and the preferred choice in today's photonic processors. Both simulations include a step-by-step 4×4 worked example of the algorithm.

5 · Imperfections and fidelity

Real MZIs have MMI imbalance (α), phase errors and loss. The quality of the implemented matrix T is measured with the fidelity:

F = |Tr(U†T)|²N · Tr(T†T)

Random phase errors degrade both meshes similarly, because both have the same number of MZIs. Loss is different: in Reck it depends on the path, so F drops faster, while Clements keeps it almost uniform. Try both in the simulations (Monte Carlo plots).

6 · Applications

  • Optical matrix–vector multiplication for neural networks (inference at the speed of light).
  • Linear-optical quantum computing and boson sampling.
  • Reconfigurable switches and routers, mode (de)multiplexing and unscrambling.
  • Beamforming networks and optical signal processing.
