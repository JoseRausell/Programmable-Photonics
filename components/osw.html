Theory

1 · Optical circuit switching

An N×N optical circuit switch connects every input to one output, following a permutation, without converting the light to electronics. It is built from 2×2 elements, here MZIs used in two digital states:

bar (θ = π):  in₁ → out₁, in₂ → out₂   ·   cross (θ = 0):  in₁ → out₂, in₂ → out₁

The architecture fixes how many switches are needed, how many each signal crosses (loss, crosstalk) and which permutations can be set up:

  • strictly non-blocking: a new connection never disturbs the existing ones (crossbar);
  • rearrangeably non-blocking: every permutation is possible, but adding a connection may require re-routing others (Beneš, Spanke–Beneš);
  • blocking: some permutations are impossible (Omega).

2 · Crossbar

An N×N grid: inputs run along the rows and outputs along the columns. The switch at (i, j) is set to drop to connect input i to output j; all the others let the light pass straight. Routing is trivial and the fabric is strictly non-blocking, but it needs N² switches and the path length depends on the connection:

nsw(i → j) = j + N − i,   from 1 to 2N − 1

so the insertion loss is very non-uniform for large N.

3 · Beneš

A recursive network: a column of N/2 switches, two Beneš networks of size N/2, and another column of N/2 switches. It needs only (N/2)(2 log₂N − 1) switches and every path crosses exactly 2 log₂N − 1 of them.

It is programmed with the looping algorithm: the two inputs of a first-column switch must go to different sub-networks (upper / lower), and so must the two outputs of a last-column switch. Starting from one input, assign it to the upper half, send the partner of its output to the lower half, then the partner of that input to the upper half, and so on until the loop closes. Then repeat inside each half.

The shuffle connections between columns create many waveguide crossings, which add loss and crosstalk.

4 · Spanke–Beneš (N-stage planar)

N columns of switches between neighbouring waveguides, alternately on pairs (1,2), (3,4)… and (2,3), (4,5)…, with N(N−1)/2 switches in total. There are no waveguide crossings, which makes it attractive for integrated photonics.

Routing is an odd–even transposition sort: label every signal with its destination; each switch crosses its two signals if they are in the wrong order. After N columns the labels are sorted, so every signal reaches its output. Paths cross between N/2 and N switches.

5 · Omega / Banyan

log₂N columns of N/2 switches, each preceded by a perfect shuffle. It has the minimum number of switches, (N/2) log₂N, and is self-routing: at column s a switch sends the signal up or down according to bit s of the destination address (most significant first).

There is a single path between any input and output, so two signals often compete for the same switch output: the Omega network is blocking. Only N^(N/2) of the N! permutations are possible; shifts are, most random permutations are not.

6 · Loss, crosstalk and comparison

A switch in either state leaks a fraction ε = 10−ER/10 to the wrong output (ER = extinction ratio). To first order, the crosstalk at an output grows with the number of switches the unwanted signals share with the path:
