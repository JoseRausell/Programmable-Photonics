1 · Transfer matrix as a product of blocks

Each element of the circuit is a 2×2 matrix acting on the field amplitudes of the two waveguides, E = (Eupper, Elower)T. The MZI matrix is the product of its blocks, written right to left in the order the light meets them:

2 · MMI coupler with imbalance

An ideal 2×2 MMI splits the power 50:50 and adds a 90° phase to the crossed path. Fabrication errors in its width or length shift the self-imaging point and unbalance the split. This is modelled with an angle error α:

MMMI(α) = sin(π/4 + α)j cos(π/4 + α)j cos(π/4 + α)sin(π/4 + α)
α = 0  →  MMMI = 1√21jj1

The matrix stays unitary for any α (the coupler remains lossless), and only the power ratio changes: sin²(π/4 + α) : cos²(π/4 + α). Current values:

With identical couplers (α₁ = α₂), the cross port still reaches a perfect zero, but the bar port has a finite extinction ratio. With different errors, both ports lose extinction.

3 · Phase shifters

A phase shifter is a diagonal matrix. Depending on the configuration:

1 internal:  P(φ₁) = ejφ₁001
2 internal:  P(φ₁, φ₂) = ejφ₁00ejφ₂ = ej(φ₁+φ₂)/2ejΔφ/200e−jΔφ/2
external:  Pext(φext) = ejφext001

Thermo-optic phase (all heaters identical; θ₀ is the fabrication offset of the internal upper arm):

φ1 = θ₀ + πP1Pπ,   φ2 = πP2Pπ,   P = I²R

4 · Ideal closed forms (α₁ = α₂ = 0)

1 internal phase shifter:

T = j ejφ/2sin(φ/2)cos(φ/2)cos(φ/2)−sin(φ/2)

2 internal phase shifters. Only the difference Δφ = φ₁ − φ₂ sets the split; the common part is a global phase:

T = j ej(φ₁+φ₂)/2sin(Δφ/2)cos(Δφ/2)cos(Δφ/2)−sin(Δφ/2)

Internal θ plus external φ at the input: this is the tunable basic unit used in meshes.

T(θ, φ) = j ejθ/2ejφ sin(θ/2)cos(θ/2)ejφ cos(θ/2)−sin(θ/2)

5 · Why use two phase shifters?

Two internal phase shifters (dual drive). Any Δφ in [−π, π] is reached by heating only one arm. Each heater then needs at most Pπ instead of 2Pπ. Driving both arms also allows push–pull operation and compensating θ₀ in either direction.

Internal + external. θ sets the splitting ratio and φ sets the relative phase between the ports. Together they give full control of the 2×2 element, which is what programmable meshes (Reck, Clements, recirculating meshes) need to interfere light coherently with other units.

With light in the upper port only, an external phase shifter at the input just adds a global phase, so the powers don't change. Select “Both ports” to see its effect. An external phase shifter at the output never changes the powers; it shifts the relative output phase (lower plot on the right).
